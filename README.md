# سامانه پزشک خانواده و یادآور واکسیناسیون کشوری

اپلیکیشن هوشمند مدیریت بهداشت و پرونده سلامت خانواده منطبق بر جدول واکسیناسیون کشوری و دستورالعمل‌های سامانه سیب وزارت بهداشت.

## ویژگی‌ها
- محاسبه خودکار موعد واکسن‌ها بر اساس سن دقیق (روز، ماه و سال)
- اعلام زمان باقی‌مانده یا میزان تأخیر هر واکسن
- تقویم هجری شمسی
- مدیریت پرونده سلامت چند عضو خانواده به صورت مجزا
- بدون وابستگی به سرور خارجی و ذخیره‌سازی آفلاین و امن
